# AnimeLove: удаление эффектов карусели

По запросу пользователя карусель переведена на один плоский экран. Удалены перспективная сцена, наклон от курсора и его обработчики, тени, маска, свечение и анимации появления. Неактивные экраны скрыты через `hidden`, без отдельных видимых слоёв. Отложенная отрисовка `content-visibility` также удалена.

На странице AnimeLove закреплённая шапка использует непрозрачный белый фон без `backdrop-filter`. Правило ограничено этой страницей. Перелистывание кнопками, клавиатурой, перетягиванием и свайпом сохранено. Автопоказ по-прежнему приостанавливается вне экрана, в скрытой вкладке, при взаимодействии и reduced motion.

## Проверка Linux + Firefox

Firefox 157.0, headless Linux, 1440×1000, DPR 1. Обычные события колеса через Playwright: 24 события по 250 px, четыре прохода вниз/вверх. Сравнивался интервал между вызовами `requestAnimationFrame`; это лабораторный показатель, не аппаратный FPS устройства пользователя.

| Версия | p95 интервала | Максимум | Интервалы длиннее 50 мс |
| --- | ---: | ---: | ---: |
| До изменения, опубликованная ревизия c4ba009 | 115,98 мс | 134,12 мс | 29 из 106 |
| После, прогон 1 | 17,28 мс | 17,38 мс | 0 из 231 |
| После, прогон 2 | 17,28 мс | 17,52 мс | 0 из 228 |
| После, прогон 3 | 17,28 мс | 17,44 мс | 0 из 227 |

Базовый замер сделан на HTTPS-сайте, три новых — на локальном сервере production-сборки после завершения загрузки. Параметры прокрутки одинаковые. Состояние аппаратного ускорения компьютера пользователя не проверялось.

## Функциональные проверки

Production-сборка, TypeScript, ESLint, 24 проверки экспорта/HTTP. Изображения и управление проверены в Chromium на ширинах 320–1920 px с DPR 1–3. В Firefox проверены все четыре изображения, один видимый экран, кнопки, клавиатура и отсутствие переполнения на 390 и 1440 px. Проверка стилей всех страниц после клиентских переходов пройдена.

Существующий сценарий паузы и возобновления автопоказа теперь выполняется в CI и в Chromium, и в Firefox. Локальный запуск Firefox:

```bash
npx playwright install firefox
CAROUSEL_BROWSER=firefox npm run test:carousel
```

Полные локальные измерения и скриншоты: `.cache/carousel-effects-removed/`. Исходная диагностика: `.cache/carousel-diagnosis/2026-10-31/`.
