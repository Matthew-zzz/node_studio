# Логотип Node Studio

Единый знак — предоставленная владельцем градиентная монограмма NS. Компонент `src/components/ui/brand.tsx` используется на сайте, в иллюстрациях студии, формах входа, кабинетах и Telegram Mini App. Служебные иконки разделов и профилей сохраняют своё назначение.

Исходник: `Градиентная монограмма NS на тёмном фоне.png`, 1254 × 1254. Контрольная сумма и область экспорта записаны в `docs/asset-generation/node-studio-avatar.json`. Рисунок не перерисовывается: уменьшаются поля и готовятся размеры для интерфейса и аватарок.

Повторный экспорт: `node scripts/prepare-brand.mjs <путь-к-исходнику.png>`. Готовые ресурсы сохраняются в `public/assets/brand/`, аватарка — в `public/assets/node-studio-avatar.png`. Маленький WebP используется всеми экземплярами знака, favicon и Apple Touch Icon подключаются в корневых метаданных. PNG-превью 1200 × 630 используется для Open Graph и Twitter; прежние пути SVG обновлены для совместимости.

Аватар Telegram-бота обновляется отдельно при замене фирменного знака. Экспорт ресурсов и сборка сайта сами не меняют внешние профили и не отправляют сообщения пользователям.
