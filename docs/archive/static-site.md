# Node Studio

Рабочее название студии. Статический адаптивный сайт на русском языке: главная страница, три подробных кейса, галереи, фильтр проектов и контакт через Telegram.

Запуск: npm run build, затем npm run dev. Локальный адрес: http://localhost:4173.

Для просмотра без сервера откройте preview.html в обычном браузере. Связанные страницы preview-autoparts.html, preview-anime-love.html и preview-vectra.html работают через локальные файлы. Обе версии собираются одной командой npm run build.

Домен для публикации на собственном сервере: https://node-studio.ru. Canonical, Open Graph, robots.txt и sitemap.xml используют этот адрес. Для установки на текущем сервере с Nginx и Certbot: `sudo bash /root/Work/portfolio/site/scripts/deploy-node-studio.sh`. Скрипт собирает и проверяет сайт, размещает статические файлы в /var/www/node-studio.ru, подключает отдельный виртуальный хост, получает сертификат Let's Encrypt, включает перенаправление HTTP → HTTPS и автоматическое обновление сертификата. При повторном запуске обновляет сайт. Конфигурации домена находятся в deploy; остальные виртуальные хосты не редактируются. Нужны права на /var/www, /etc/nginx, /etc/letsencrypt и управление Nginx через systemd. DNS-запись A для node-studio.ru должна указывать на IPv4 сервера; если есть AAAA, она должна указывать на рабочий IPv6 этого же сервера. Порты 80 и 443 должны быть доступны извне. Поддомен www отдельно не подключается.

Перед публикацией scripts/check-domain-dns.mjs проверяет, что DNS-запись A для node-studio.ru указывает на адрес текущего сервера 144.31.215.204. При отсутствии домена или неверном IP скрипт останавливается до сборки, изменения Nginx и запроса сертификата. Отдельная проверка DNS: `node scripts/check-domain-dns.mjs`.

Для нового домена доступен запуск `sudo bash /root/Work/portfolio/site/scripts/deploy-node-studio.sh --wait-dns`: до 24 часов проверяет DNS раз в 5 минут и после появления нужного IP продолжает публикацию. Для фонового запуска из root-терминала: `nohup bash /root/Work/portfolio/site/scripts/deploy-node-studio.sh --wait-dns > /root/Work/portfolio/deploy-node-studio.log 2>&1 &`. Ход выполнения записывается в deploy-node-studio.log. Одновременные запуски блокируются через flock. Сертификат запрашивается только после успешной проверки DNS; при ошибке дальнейшей публикации скрипт завершается без автоматического повторения запросов сертификата.

Временное размещение на scorevo.ru: `sudo bash /root/Work/portfolio/site/scripts/deploy-scorevo.sh`. Скрипт использует существующий сертификат scorevo.ru, сохраняет исходную конфигурацию в /var/backups/portfolio-scorevo/scorevo.ru.before-portfolio.conf и размещает отдельную сборку в /var/www/scorevo-portfolio. Главная и страницы сайта переключаются с Herdr на портфолио; /api/, /ws/ и прежние файлы Herdr сохраняются, для старых /assets/ действует fallback. Проверяются страницы, ответы 404 и точное совпадение главной по HTTPS локально и через публичный домен; при ошибке возвращается предыдущая конфигурация Nginx. Возврат исходного сайта: `sudo bash /root/Work/portfolio/site/scripts/deploy-scorevo.sh --restore`. Ожидание DNS node-studio.ru продолжает работать отдельно. Сборщик поддерживает SITE_ORIGIN и SITE_OUTPUT_DIR; временная сборка использует .cache/scorevo-dist и не изменяет обычный dist или локальные preview-файлы.

Проверка: npm run check. Внешние npm-зависимости для сборки и работы не нужны.

Содержание и контакты: src/content.mjs. Структура страниц: src/templates.mjs. Стили: src/styles.css. Интерактивность: src/main.js. Результат сборки находится в dist.

Повторяющаяся сетка функций убрана из страниц, возможности показаны скриншотами с короткими подписями. Vectra остаётся собственным продуктом, автомагазин — локальным решением для сотрудников; заметка об изменении дизайна сохранена. Новых показателей эффективности и обещаний удержания аудитории нет. Стили этого представления находятся в src/project-stories.css.

Знак Node унифицирован в src/brand.mjs: шапка, мобильное меню, подвал и обе иллюстрации используют один компонент из четырёх модулей. Прежний знак в виде вертикальных полос удалён из схем продукта и доработки сервиса; favicon также повторяет логотип из шапки. Первый экран содержит один короткий абзац, кнопку и условия общения. Услуги представлены восемью раскрывающимися направлениями: сайты, проект с нуля, доработка, интеграции, боты и мини-приложения, скрипты и автоматизация, внедрение ИИ и «И ещё кое-что» для нестандартных задач из любой сферы. Все пункты изначально закрыты; одновременно открыт один. Внутри — подробное описание, три примера задач, результат и ссылка на реальный кейс, где он подходит. Общие описания берутся из тех же данных, что и в компьютерной версии. На компьютере сохранены пять крупных иллюстраций. В проектах на телефоне показаны короткое название и результат; полный рассказ и все скриншоты остаются на страницах кейсов. Четыре этапа представлены вертикальной последовательностью с иконками. В контакте оставлена одна основная кнопка, пример сообщения и часы ответа. Основной текст сохраняет размер 15–17 px, между блоками увеличены отступы.

Полные тексты для широких экранов сохранены; src/responsive-copy.mjs формирует пары data-copy-wide/data-copy-compact. CSS показывает одну версию, а скрытые варианты не попадают в дерево доступности. Раскрытие услуг использует нативные details/summary с управлением с клавиатуры. Атрибут name и небольшой обработчик toggle закрывают предыдущий пункт; без JavaScript содержание также доступно. Движение учитывает prefers-reduced-motion. Карусели, просмотр изображений и внешние библиотеки не добавлены. Крупные статичные скриншоты и переходы к кейсам сохранены. Первый дублирующий пример загружается лениво. Браузерная проверка в текущей среде недоступна; выполнены сборка, проверка ссылок, метаданных, структуры HTML и JavaScript.

На главной добавлены две непрерывные горизонтальные строки: направления студии после первого экрана и технологии перед проектами. Текстовая строка движется влево, строка иконок — вправо. Использованы мягкие маски по краям, тонкие границы и сине-фиолетовый фон. На телефоне сохранены читаемый текст и крупные иконки. Одинаковые группы и промежутки обеспечивают бесшовный цикл; повторы скрыты от программ чтения с экрана. При наведении движение приостанавливается, вне экрана и на скрытой вкладке — останавливается; prefers-reduced-motion и отсутствие JavaScript показывают все элементы статично с переносом. Код: src/marquees.mjs, src/marquees.css; управление движением подключено к существующему src/solutions.js.

Референс анимации: https://magicui.design/docs/components/marquee. Векторные иконки Python, Node.js, FastAPI, MongoDB, Next.js, React, PostgreSQL, Telegram, LangChain, JavaScript, Vercel, Railway и GitHub взяты из Simple Icons: https://github.com/simple-icons/simple-icons/tree/develop/icons. Оригинальные фотографии в родительской папке сохранены. В сайт включена очищенная версия списка аналогов из edited. При её обработке imagegen пересоздал изображение; это не точная пиксельная копия исходника.

В кейсе автомагазина описан реализованный сценарий подбора. Оценочное сравнение времени убрано из заголовка, результата и отдельного блока метрик: в новой редакции доверие строится на демонстрации функций. Vectra — собственный продукт, а не название студии. Автоматическая поддержка ИИ-агентом пока не реализована и на сайте не предлагается. Цены и участники команды не публикуются.

Проверки HTML, ссылок, изображений, анонимизации и JavaScript пройдены. В текущей среде запрещён запуск HTTP-сервера и браузера, поэтому визуальная проверка не выполнена. Публикация Sites не завершена: DNS сервера исходников git.chatgpt-team.site недоступен. Идентификатор созданного закрытого Site сохранён в .openai/hosting.json; при возобновлении публикации нужно использовать его.

Первый экран показывает статичное изображение автомагазина. Изображения автомагазина представлены как визуальная концепция интерфейса; исходные кадры сохранены в файлах проекта. Вступление конкретизирует задачи: перенос данных, сайты и Telegram-приложения, ИИ по документам. Возможности представлены пятью крупными визуальными сценами с узнаваемыми проблемами клиента. Анимации поддерживают уменьшение движения и не требуют внешних библиотек. Под первой кнопкой «Обсудить задачу» добавлено небольшое сине-фиолетовое свечение с мягкой тенью, без пульсации.

Референсы композиции: https://linear.app/ (показ рабочего интерфейса и сценариев), https://www.instrument.com/ (подача реальных работ), https://vercel.com/ (продуктовые разделы). Чужие тексты, иллюстрации и брендинг в сайт не перенесены.

Блок объясняет переносимые компетенции без привязки к отраслям или портфолио: интеграции между системами, автоматизация, создание сайтов/кабинетов/Telegram-приложений, внедрение ИИ и доработка существующего продукта. В src/solutions.mjs массив clientSituations содержит пять формулировок пользователя, адаптированных к голосу студии. Каждый заголовок называет знакомую проблему, а один короткий абзац объясняет предлагаемое решение. Прежние списки из 20 ситуаций заменены этими формулировками. Все пять иллюстраций сохранены; пятая показывает добавление нужных функций к готовому сервису. Изображения интерфейсов и цепочек — примеры возможностей, а не дополнительные клиентские кейсы. HTML/CSS/SVG сохраняют чёткость и адаптируются под телефон; выбор категорий и раскрытие текста не требуются.

По уточнению все тексты написаны от имени студии, при этом общение остаётся напрямую с разработчиком. Обновлены метаописание и обложка для ссылок; короткий слоган добавлен в подвал. Возле услуг размещён отдельный акцентный блок «Вам не нужно переводить свою работу на язык разработки» с продолжением «мы разберёмся в специфике вашей сферы и поможем…». Он оформлен как открытая полоса с иконками сообщения и разработки, мягким градиентом и крупным заголовком. Для трёхстрочного вступления, приглашения и слогана добавлены отдельные мобильные стили.

Анимации приостанавливаются вне видимой области и на скрытой вкладке; при prefers-reduced-motion остаётся статичный фон. Используются встроенные SVG/CSS, без видео, WebGL и внешних библиотек. Модуль src/hero-atmosphere.mjs, стили src/hero-atmosphere.css, управление src/hero-atmosphere.js; загружаются только на главной странице.

Референсы фонового движения изучены по официальным страницам https://vercel.com/fluid, https://linear.app/ и разбору https://stripe.com/blog/connect-front-end-experience. Выбрана адаптация идеи потоков и связей для автоматизации, а не перенос чужих иллюстраций или исходного кода.

Мобильная версия переработана отдельно в src/mobile.css и src/mobile.js. До 900 px шапка содержит бургер; меню открывается справа как нативный модальный dialog с затемнением, удержанием фокуса и блокировкой прокрутки страницы. Закрытие: крестик, фон, Escape, выбор ссылки, переход на широкий экран или свайп вправо по верхней части панели. Учитываются безопасные области экрана и настройка уменьшения движения.

До 760 px основные тексты увеличены до 15–17 px, действия — до 44–56 px по высоте; карточки и услуги выстроены в одну колонку. Для телефона используются отдельные вертикальные изображения через picture/source, без прежнего растягивания широкого кадра до 900 px и прокрутки внутри каждого изображения. Обёртки: src/screen-preview.mjs и src/responsive-media.mjs. Вертикальные кадры показаны статично по ширине страницы. Просмотрщик, увеличение и сравнение с исходником удалены; исходники остаются в файлах проекта. Настройки viewport не запрещают масштабирование браузера. В этой среде доступна проверка сборки и программных состояний; визуальный прогон в мобильном браузере не выполнен.
