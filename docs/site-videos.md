# Фоновое видео главной

Первый экран и карточка NodeStudio AI используют общий компонент `ViewportVideo`. Он подключает источник только при появлении видео в области просмотра, ставит воспроизведение на паузу вне неё, при скрытии вкладки и при включении `prefers-reduced-motion`. Скрытые фильтром карточки не воспроизводятся. Повторное появление продолжает воспроизведение с текущего места.

Первый ролик проигрывается один раз. После завершения источник отсоединяется, медиаресурс освобождается, остаётся заранее загруженное изображение последнего кадра. При следующем появлении в области просмотра видео заново не запускается. После полной перезагрузки страницы цикл доступен снова.

Для фонового видео первого экрана на устройствах до 760 px выбирается вариант 1280 × 720; на больших — 1920 × 1080. Вариант сохраняется до конца воспроизведения, поэтому поворот устройства не запускает ролик заново. Частота исходных кадров сохраняется: 60 кадров/с у первого экрана и 24 кадра/с у видео ИИ-агента.

NodeStudioAI занимает полный ряд портфолио: текст и кнопка слева, видео справа. До 760 px блок становится вертикальным. Видео 1280 × 720 показывается целиком в пропорциях 16:9. Исходник заменён на загруженный пользователем `gemini_generated_video_48b8acc9.mp4` от 1 ноября 2026 года; тот же ролик используется на странице проекта.

## Подготовка ресурсов

На машине с установленным FFmpeg выполните:

```bash
npm run assets:videos
```

Исходники — `public/assets/node-studio-home-hero.mp4` и `public/assets/nodestudio-ai-showcase.mp4`. Скрипт последовательно создаёт H.264 / yuv420p с `faststart` в `public/assets/video/`, полностью удаляет аудио, подготавливает изображения и записывает размеры и контрольные суммы исходников в `docs/asset-generation/site-videos.json`. Генерируемые ресурсы включаются в коммит; FFmpeg не требуется при сборке Docker-образа.

Параметры сжатия: x264 slow, CRF 23 для настольного первого экрана и ИИ-агента, CRF 24 для мобильного первого экрана. Исходники служат мастерами для повторного экспорта; пользовательские страницы используют подготовленные версии.
