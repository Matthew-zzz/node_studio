# Прокрутка карточек и стили страниц

## Карточки услуг

`service-card-timeline.ts` вычисляет границы этапов по исходным высотам, отступу между карточками, положению списка и высоте окна. Первая карточка открыта. Следующая начинает расти, когда карточка за ней полностью видна; её нижняя граница остаётся у края окна. Последняя использует собственную нижнюю границу. Обратная прокрутка закрывает этапы в том же порядке.

Размеры читаются вместе при загрузке, изменении окна, загрузке шрифтов или изменении предшествующих блоков, в том числе фильтров проектов. При обычной прокрутке используются сохранённые размеры. В DOM записываются только изменившиеся высоты и фазы. Высота задаётся напрямую, чтобы изменяемая наследуемая CSS-переменная не инвалидировала стили всего SVG-поддерева.

IntersectionObserver отключает обновления вне экрана; отдельно обрабатывается прямой переход через весь список. В скрытой вкладке запланированный кадр отменяется. Все наблюдатели и обработчики удаляются при уходе со страницы.

## Стили

В корневом layout остаются шрифты, переменные, общая геометрия, навигация, контакты, темы и ошибки. Главная подключает `home-content.css` и `landing.css`; проекты — `presentation.css` и `case-page.css`; оферта — `terms.css`. Старые иллюстрации и прежний первый экран подключают свои стили только через собственные компоненты. Неиспользуемые правила прежних карточек и демонстраций удалены из общих файлов.

Сохранён относительный порядок правил и адаптивных переопределений. Общие темы и мобильный подвал остаются общими, чтобы клиентская навигация не меняла оформление в зависимости от посещённых страниц.

## Проверка и замер 30 октября 2026

Chromium, окна 1440 × 1000 и 390 × 844, одинаковая прокрутка шагом 18 px на кадр. Сравнение старой опубликованной версии и новой локальной сборки:

| Операция обработчика за проход | 1440 px до → после | 390 px до → после |
| --- | ---: | ---: |
| Чтения вычисленных стилей карточек | 1245 → 0 | 1146 → 0 |
| Записи высоты | 1185 → 69 | 1078 → 115 |
| Чтения размеров при прокрутке вне списка | 83 → 0 | 83 → 0 |

Фазы совпали во всех записанных контрольных точках. Максимальное расхождение высоты — менее 0,001 px. В этом замере суммарное время RecalcStyle сократилось со 116 до 67 мс на большом экране и со 145 до 45 мс на узком. Это измерение конкретного прохода, не обещание одинакового FPS на всех устройствах. Изменение высоты по-прежнему требует layout для сохранения поведения списка.

Повторяемые проверки:

```bash
npm run build
npm test
npm run test:services
npm run test:styles
npm run test:images
npm run test:carousel
```

`test:services` проверяет физическое положение карточек, все этапы в обоих направлениях, доступность действий, прямые переходы, фильтры и изменение окна. `test:styles` сравнивает прямую загрузку с последовательными клиентскими переходами, проверяет FAQ и меню. В CI запускаются оба набора. Для опубликованного сайта задаются `SERVICE_CARDS_ORIGIN` и `PAGE_STYLES_ORIGIN`.
