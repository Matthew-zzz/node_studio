# Скриншоты страниц проектов

Обложки, галереи и карусель AnimeLove используют общий `Screenshot` с нативным `<picture>`. WebP-варианты подготовлены заранее для статического экспорта; серверная оптимизация изображений не требуется. Браузер выбирает размер через `srcset` и `sizes`, учитывая ширину блока и плотность экрана.

Исходники и их размеры зарегистрированы в `src/features/projects/data/screenshots.ts`. После замены или добавления скриншота:

```bash
npm run assets:screenshots
npm run build
npm test
npm run test:images
```

Генератор использует Sharp, создаёт ширины 320, 480, 640, 768, 1024, 1280 px и исходную ширину, исключая увеличение. WebP из PNG имеет качество 90, из ранее сжатых JPEG — 82. Пропорции сохраняются, кадрирование при экспорте не применяется. Результаты в `public/assets/screenshots/`, сгенерированный `responsive-screenshots.ts` и отчёт с контрольными суммами в `docs/asset-generation/project-screenshots.json` включаются в коммит.

На экранах до 760 px сохраняются существующие портретные исходники. Карусель использует широкие кадры на всех устройствах, как и прежде. Размеры источников в `<source>` резервируют место для мобильного изображения до загрузки. PNG/JPEG служат запасными форматами. Галереи загружаются лениво; первая обложка имеет высокий приоритет без отдельной предзагрузки запасного PNG.

Суммарный размер 19 исходников — 20 535 938 байт; соответствующих WebP в максимальном размере — 2 110 028 байт (на 90% меньше). Это сравнение полного набора, а не размер загрузки одной страницы. Меньшие варианты дополнительно сокращают загрузку на небольших экранах.

## Проверки

`npm run test:images` проверяет декодирование всех 101 WebP-вариантов, размеры, пропорции, отсутствие увеличения и сохранность исходников. Затем поднимает временный сервер экспорта и запускает Chromium: все три страницы на ширинах 320, 390, 760, 768, 1024, 1440 и 1920 px с DPR 1–3. Проверяются выбор размера, отсутствие дублирующих загрузок PNG/JPEG, ошибок запросов и горизонтального переполнения, все слайды, управление клавиатурой, мышью и касанием, изменение ширины и запасные форматы без JavaScript.

Для проверки опубликованной версии:

```bash
PROJECT_IMAGES_ORIGIN=https://node-studio.ru npm run test:images
```

Дополнительно при подготовке сравнивались реальные размеры блоков до и после на 390, 820 и 1440 px и фрагменты изображений с мелким текстом. Размеры блоков сохранились. Проверки в браузере эмулируют размеры и плотность экрана, а не заменяют проверку на физических устройствах.
