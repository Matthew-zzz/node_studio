# Изображения карточек проектов

Три карточки на главной используют `<picture>` с подготовленными WebP-изображениями. Исходники: `public/assets/vectra-showcase.png`, `public/assets/autoparts-showcase.png`, `public/assets/animelove-showcase.png`.

После замены исходника выполните:

```bash
npm run assets:showcases
```

Скрипт сохраняет WebP в `public/assets/showcase/` и обновляет `src/features/projects/data/showcase-images.ts`. Для текущих исходников создаются размеры 480, 640, 768, 1024 и 1254 px с качеством 90; изображения не увеличиваются. Генерируемые файлы необходимо включать в коммит.

`ShowcaseImage` задаёт `srcset` и `sizes` с учётом сетки, отступов и плотности экрана. Загружается подходящий вариант; PNG служит запасным форматом для браузеров без WebP. Источники подключены до `<img>`, предзагрузка картинок не используется. Кадрирование и анимация наведения задаются стилями карточки.

Готовые изображения обслуживаются статическим сервером. Включать серверную оптимизацию Next.js для этого не требуется.
