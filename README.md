# Node Studio

Публичный сайт студии: главная, страницы проектов и публичная оферта. Сайт собран как статический экспорт Next.js и обслуживается Node.js без API, Telegram-бота, кабинета и авторизации.

## Локальная разработка

Нужны Node.js 24 и npm 10+.

```bash
npm ci
npm run dev
```

Сборка и локальный просмотр:

```bash
npm run build
npm run preview
```

## Docker

Для запуска с существующим Nginx:

```bash
docker compose up -d --build --wait
docker compose ps
```

Контейнер обслуживает только статический сайт на `127.0.0.1:3158`. Nginx проксирует домен на этот порт. Подробности — в [документации размещения](docs/deployment.md).

Старая база панели сохранена в отдельном Docker-томе, но больше не подключается к приложению. До отдельного решения том не удалять.

## Структура

```text
src/app/                 # Главная, кейсы, публичная оферта
src/components/          # Общие элементы сайта
src/features/home/       # Главная страница и контент
src/features/projects/   # Портфолио и страницы проектов
src/features/services/   # Описание услуг
src/features/legal/      # Стили юридической страницы
public/                  # Изображения, видео и шрифты
scripts/                 # Сборка и статический сервер
deploy/nginx.conf        # HTTPS-домен → контейнер
```
