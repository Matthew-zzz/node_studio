# NODO Studio — frontend

Фронтенд существующего сайта NODO Studio на **Next.js 16, React 19 и TypeScript**. Сохранены главная, три кейса, адаптивные изображения и Telegram-контакт. Маршруты используют App Router; страницы предварительно собираются в HTML.

## Запуск

Нужны Node.js 24 LTS и npm 10+.

```bash
npm ci
npm run dev
```

Сайт доступен на `http://localhost:3000`. При необходимости скопируйте `.env.example` в `.env.local` и задайте `SITE_ORIGIN` — домен для canonical, Open Graph, sitemap и robots. Контакты и тексты студии находятся в `src/config/site.ts`.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Разработка с обновлением страницы |
| `npm run build` | Production-сборка; результат в `out/` и совместимой копии `dist/` |
| `npm run preview` | Проверка `dist/` на `http://localhost:4173` |
| `npm run lint` | ESLint, правила React и Next.js, границы модулей и оформление JSX |
| `npm run lint:fix` | Автоматическое исправление поддерживаемых правил |
| `npm run typecheck` | Строгая проверка TypeScript |
| `npm test` | 9 проверок экспорта и 6 проверок расчёта/имитации платежей; сначала выполните build |
| `npm run test:payments` | Проверки оплаты без сборки: наценка, копейки, ошибки и отмена |
| `npm run check` | Lint, TypeScript и тесты готовой сборки |
| `npm run test:e2e` | Chromium: четыре размера экрана, меню, переходы, FAQ, копирование и состояния анимации |
| `npm run test:deploy` | Публикация статического релиза, атомарное переключение и откат; нужен Python 3.12+ |

Перед изменениями и отправкой кода:

```bash
npm run lint
npm run typecheck
npm run build
npm test
```

Для браузерных проверок один раз установите Chromium:

```bash
npx playwright install chromium
npm run test:e2e
```

Скриншоты сохраняются в `test-results/screenshots/`. Для уже установленного браузера можно задать `CHROMIUM_EXECUTABLE`. GitHub Actions из `.github/workflows/ci.yml` проверяет изменения в `main` и pull request. После успешной проверки `main` готовый экспорт публикуется в `production`. Установленная на сервере служба проверяет эту ветку каждые 30 секунд и обновляет сайт с откатом при ошибке. Для первого включения выполните [однократную установку](docs/deployment.md).

В изолированной среде с запретом дочерних процессов доступна сборка через потоки с сохранением проверки типов:

```bash
NEXT_BUILD_WORKER_THREADS=1 npm run build
```

В изолированной рабочей среде браузерный прогон недоступен: локальный HTTP-сервер получает `listen EPERM`. Полный прогон выполняется в GitHub Actions; локально его можно запустить в среде, разрешающей HTTP-сервер и Chromium.

## Тестовая оплата

После `npm run dev` откройте `http://localhost:3000/payment-demo/` (для `npm run preview` — порт 4173). Доступны успех, ошибка, отмена, повторная попытка и переключение темы. В раскрывающихся «Параметрах теста» можно изменить сумму и проверить наценку: +30% для пожелания, без наценки для основной разработки.

Это заглушка в памяти браузера: деньги не списываются, реальный доступ не выдаётся, после обновления страницы результат сбрасывается. Сервер, банк и платёжные ключи не требуются. `MockPaymentCard` подготовлен для встраивания в будущий чат проекта. Подробности — в [требованиях к кабинетам](docs/client-portal.md).
